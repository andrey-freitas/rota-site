# Site público do Rota do Engenheiro

Páginas públicas do aplicativo **Rota do Engenheiro** (estudo para concursos
de engenharia), servidas em `rotadoengenheiro.com.br` pela Vercel:

- `/politica-de-privacidade` — Política de Privacidade
- `/excluir-conta` — instruções de exclusão da conta

Estático por enquanto; o site completo (Next.js) substituirá este conteúdo
no mesmo domínio, preservando as URLs.
